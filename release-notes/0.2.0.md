- New setting **Tree style**: *Family tree* (as before) or *Phylogenetic tree*. The phylogenetic style draws the tree as a cladogram: right-angled branches that split at a shared bar, with every note at the end of a branch lined up at the far edge, so the leaves read as one list whatever their depth. Notes are drawn as plain labels on the branches; the current note keeps its highlight. It works in both layout directions and reads best left to right.
- Code blocks take `style: phylogenetic` (or `style: boxes`) to choose per block; without it they follow the setting.
