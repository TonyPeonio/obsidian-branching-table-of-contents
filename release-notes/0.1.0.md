First release.

- Notes linked with `parent` / `child` properties (configurable names) form a tree; either direction is enough, and notes may have several parents and children.
- **Family tree view**: the active note with its ancestors above and descendants below (levels configurable, default 2 and 2), drawn as a tidy branching tree with pan and zoom. Click to open, Ctrl-click for a new tab, right-click for a menu, hover for page preview. Pin to stop following the active note.
- **Outline** mode (collapsible nested list) and **whole vault** scope (a forest of every root).
- **Breadcrumbs** at the top of every note with a parent; a `+N` chip lists other parents.
- ` ```branching-toc ``` ` code block renders a subtree (outline or drawn tree) inside a note.
- Commands: open tree view, reveal current note, create child / parent note (writes the link property), generate a table-of-contents note of nested wikilinks for any root.
- Multi-parent notes are marked *also under …*; cycles are detected and marked; links to notes that do not exist yet are drawn dashed and create the note on click.
- Optional `toc-order` property to order siblings; exclude-folders setting; top-down or left-right layout.
